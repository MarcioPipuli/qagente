# QAGente

Para tarefas de Qualidade de Software, leia `AGENTS.md` e `.qagente/quality-profile.json` antes de agir. Aplique o perfil do projeto para idioma, formato, diretórios, níveis de risco, frameworks e convenções.

Preserve rastreabilidade, análise por risco, independência dos testes, proteção de segredos, registro de lacunas e evidência real de execução. Não altere código de produção como parte de uma tarefa de QA sem solicitação explícita.
